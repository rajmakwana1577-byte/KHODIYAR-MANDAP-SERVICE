## 📝 Customization Guide

### Changing Colors
Edit `:root` variables in `styles/main.css`:
```css
:root {
    --primary-purple: #3d1429;
    --primary-burgundy: #5e1d3b;
    --primary-gold: #d4af37;
    /* ... etc */
}
```

### Changing Fonts
Edit Google Fonts link in `index.html` head section

### Adding More Gallery Images
1. Add new `<div class="gallery-item" data-category="...">` in HTML
2. Update gallery-grid CSS if needed
3. Add corresponding images to `/assets/images/`

### Modifying Content
All text content is editable in `index.html`. Simply replace placeholder text while keeping HTML structure intact.
